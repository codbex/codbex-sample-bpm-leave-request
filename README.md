# codbex-sample-bpm-leave-request
A [Hyperion](https://www.codbex.com/products/hyperion/) sample project for leave requests management using BPM.<br>
More details about the project in [this blog](https://www.codbex.com/technology/2024/07/17/leave-request-bpm-app/).

## Project versions
- Use [main](https://github.com/codbex/codbex-sample-bpm-leave-request/tree/main) branch to run the scenario described in the blog (Hyperion 1.0.7)
- Use [hyperion_2_61_0](https://github.com/codbex/codbex-sample-bpm-leave-request/tree/hyperion_2_61_0) to run the scenario with **Hyperion 2.61.0**
- Branch [hyperion_2_60_0](https://github.com/codbex/codbex-sample-bpm-leave-request/tree/hyperion_2_60_0) is adapted for **Hyperion 2.60.0**
